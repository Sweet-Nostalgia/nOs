# nOs
The reason why I started this project was as a goal to myself to build a fully working video game engine. There are pre-existing Engines out there as well. But I am willing to learn everything myself. Majority of these concepts I have been teaching myself and also using sources like Microsoft Learn, Frank D. Luna's Introduction to DirectX11 and mainly a Tutorial series on YouTube by Frostbite developer Yan Chernikov: https://www.youtube.com/playlist?list=PLlrATfBNZ98dC-V-N3m0Go4deliWHPFwT

## Features
- I built my own logging class and logger system to learn how to debug errors that arise and see if any inputs are taken in by the program.
- I used Win32 and DirectX11 as to achieve very low level programming and shader systems instead of finding a simpler API like OpenGL that can have multiple layers of abstraction.

## Output
- Regarding my progress on the project as it is continuing, there must be an output of an orange triangle on a purple screen. That is to show the DirectX graphical API that is installed in your Windows device is operational.

## What's Next?
- I have been looking into Physics APIs and Mathematical APIs that my Engine would cater to its goals which is mainly to build racing games so I have been reading a lot about APIs that must also be cross-platform and also very accurate to the real world problems so when the projects get built on the software, they make sense even to those who do not have a braoder understanding of physics beyond collision physics.
